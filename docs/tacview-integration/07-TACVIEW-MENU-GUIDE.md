# Tacview Menu - Pan Configuration Guide

## Overview

This document describes how users configure spatial audio (stereo pan) directly in Tacview's menu system. Pan configuration is **NOT** done in AeroDebrief - AeroDebrief receives and applies the pan values set in Tacview.

**Scenario**: User has 4 pilots with manual pan settings, switches to Auto

   - Viper 1-1: -0.8
   - Viper 1-2: -0.2
   - Viper 1-3: +0.3
   - Viper 1-4: +0.9

   - Viper 1-1: -1.0 (calculated)

     - Viper 1-3: +0.3
     - Viper 1-4: +0.9

## Pan Value Reference

### Preset Values

| Preset | Value | Position | Use Case |
|--------|-------|----------|----------|
| Full Left | -1.0 | Far left ear only | Single pilot on left |
| Mostly Left | -0.7 | Predominantly left | Left formation flight |
| Slightly Left | -0.3 | Slightly left | Near-center left |
| Center | 0.0 | Both ears equally | Single pilot or lead |
| Slightly Right | +0.3 | Slightly right | Near-center right |
| Mostly Right | +0.7 | Predominantly right | Right formation flight |
| Full Right | +1.0 | Far right ear only | Single pilot on right |

### Audio Mix Calculation

For a given pan value `p`:
```
Left Channel Gain = (1.0 - p) / 2.0
Right Channel Gain = (1.0 + p) / 2.0
```

Examples:
- Pan = -1.0: Left = 1.0, Right = 0.0 (full left)
- Pan = 0.0: Left = 0.5, Right = 0.5 (center)
- Pan = +1.0: Left = 0.0, Right = 1.0 (full right)
- Pan = -0.7: Left = 0.85, Right = 0.15 (mostly left)
- Pan = +0.4: Left = 0.3, Right = 0.7 (slightly right)

## Technical Notes

### Lua Implementation

Pan manager stores mode and manual settings:
```lua
local PanManager = {
    mode = "auto", -- Current mode
    manualPanSettings = {
        ["pilot-1-guid"] = -0.7,
        ["pilot-2-guid"] = 0.4
    }
}
```

### Protocol Message

Tacview sends pan mode with pilot selection:
```json
{
  "type": "pilot_selection",
  "pan_mode": "manual",
  "selected_pilots": [...]
}
```

## FAQ

**Q: Can I adjust pan in AeroDebrief?**  
A: No. Pan is configured exclusively in Tacview's menu. AeroDebrief displays the current pan values but does not provide UI to change them.

**Q: What happens if I switch from Manual to Auto?**  
A: Auto mode recalculates pan values automatically. Your manual settings are saved and will be restored if you switch back to Manual.

**Q: Can I have different pan settings for different missions?**  
A: Pan settings are per-pilot-ID. If the same pilot appears in multiple missions, their manual pan setting will be reused.

**Q: What if I select 10 pilots in Auto mode?**  
A: They will be evenly distributed from -1.0 to +1.0. With 10 pilots, the spacing is approximately 0.22 apart.

**Q: Can I use custom pan values like -0.567?**  
A: Yes! The Custom option allows any value between -1.0 and +1.0 with decimal precision.
