## User Experience Paths

### Path 1: Typical User (99% of users)

```
Install Addon ? Start Tacview ? ? Works!
                    ?
            (Tacview 1.9.0+ has LuaSocket built-in)
```

**Log Output**:
```
AeroDebrief Sync: Using Tacview's built-in LuaSocket
AeroDebrief Sync: LuaSocket version: 3.0
AeroDebrief Sync: TCP server listening on 127.0.0.1:52001
? All systems operational
```

### Path 2: User with Older Tacview (1% of users)

```
Install Addon ? Start Tacview ? ? Error in log
                    ?
            "module 'socket' not found"
                    ?
            Read LUASOCKET.md
                    ?
            Follow lib/MANUAL-INSTALL.md
                    ?
            Download LuaSocket ? Copy to lib/
                    ?
            Restart Tacview ? ? Works!
```

**Log Output (after manual install)**:
```
AeroDebrief Sync: Using LuaSocket from lib folder
AeroDebrief Sync: LuaSocket version: 3.0
AeroDebrief Sync: TCP server listening on 127.0.0.1:52001
? Fallback successful
```

### Path 3: User Chooses to Upgrade (Recommended)

```
Install Addon ? Start Tacview ? ? Error
                    ?
            Read LUASOCKET.md
                    ?
            "Upgrade Tacview to 1.9.0+ (Recommended)"
                    ?
            Upgrade Tacview
                    ?
            Restart ? ? Works automatically!
```
