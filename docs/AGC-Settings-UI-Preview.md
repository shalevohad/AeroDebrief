## Slider Behavior Examples

### Target Level Slider
```
Very Quiet        Normal         Very Loud
    ?               ?                ?
-30 -25 -20 -15 -10 -5  0  +5  +10 dB
        ?
    Current: -20.0 dB

Moving left  = Quieter normalization (more headroom)
Moving right = Louder normalization (less headroom)
```

### Maximum Boost Slider
```
No Boost              Moderate            Aggressive
   ?                     ?                     ?
   0   +5  +10  +15  +20  +25  +30 dB
                        ?
                Current: +20.0 dB

Moving left  = Less boost for quiet pilots
Moving right = More boost for quiet pilots (may amplify noise)
```

### Maximum Cut Slider
```
Aggressive        Moderate         No Cut
    ?                ?                ?
  -20  -15  -10  -5   0 dB
            ?
    Current: -10.0 dB

Moving left  = More attenuation for loud pilots
Moving right = Less attenuation (preserves dynamics)
```

## Color Palette

### AGC Section Border
- **Accent**: `#1976D2` (Blue)
- **Border Width**: `2px`
- **Corner Radius**: `8px`

### Background
- **Section**: `#F5F5F5` (Light Gray) or `#2E2E2E` (Dark)
- **Window**: `#FFFFFF` (Light) or `#1E1E1E` (Dark)

### Text
- **Header**: `#212121` (Dark) or `#FFFFFF` (Light)
- **Body**: `#424242` (Gray) or `#E0E0E0` (Light Gray)
- **Help**: `#757575` (Secondary Gray)
- **Values**: `Monospace Font, #1976D2` (Accent Blue)

### Controls
- **Slider Track**: `#BDBDBD` (Gray)
- **Slider Thumb**: `#1976D2` (Blue)
- **Checkbox**: `#1976D2` when checked
- **Button**: `#1976D2` primary, `#757575` secondary

## Keyboard Navigation

```
Tab Order:
1. [Enable AGC Checkbox]
   ?
2. [Target Level Slider]
   ?
3. [Max Boost Slider]
   ?
4. [Max Cut Slider]
   ?
5. [Reset AGC Button]
   ?
6. [Activity Threshold Slider]
   ?
   ... (other controls)

Shortcuts:
- Tab: Next control
- Shift+Tab: Previous control
- Space: Toggle checkbox / Activate button
- Arrow Keys: Adjust sliders (Left/Right: ±1 dB, PgUp/PgDn: ±5 dB)
- Enter: Activate focused button
- Escape: Cancel dialog
```

## Live Value Updates

As user drags slider, value display updates in real-time:

```
Before:
Maximum Boost (dB)                                    +20.0 dB

During Drag:
Maximum Boost (dB)                                    +23.5 dB
                                                      ? 
                                              (Updates live)

After Release:
Maximum Boost (dB)                                    +24.0 dB
                                                      ?
                                              (Snaps to tick)
```
