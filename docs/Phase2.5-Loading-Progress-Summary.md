## Key Features

### 1. Dynamic Progress Modes
- **Indeterminate**: Used during initialization and file opening
- **Determinate**: Used when percentage progress is available
- Smooth automatic switching between modes

### 2. Real-Time Status Updates
- "Initializing..." - When file selection starts
- "Preparing file..." - During validation
- "Opening file..." - When PlaybackSessionManager starts
- "Analyzing frequencies... X%" - During frequency analysis
- "Loading tiles... X%" - During tile loading (if applicable)
- "File loaded successfully" - On completion

### 3. Progress Percentage Display
- Only shown when progress is determinate (percentage known)
- Displayed below progress bar: "25%", "50%", etc.
- Updates smoothly every 5% to avoid flickering

### 4. Error Handling
- Clear error messages: "File not found", "Invalid file format", etc.
- Progress bar disappears on error
- Loading state properly reset
- User can try again immediately

## How It Works

```
FileSourceViewModel initializes loading state
    ?
UnifiedPlayerViewModel.OnFileLoaded() called
    ?
Progress<string> reporter created
    ?
PlaybackSessionManager reports status updates
    ?
Progress reporter forwards to FileSourceViewModel
    ?
FileSourcePanel UI updates automatically via binding
    ?
User sees real-time progress
```
